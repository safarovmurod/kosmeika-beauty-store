## Применение

`node --import tsx scripts/import-catalog-20261108.ts` — предварительный просмотр плана без записи в БД. `--preview` создаёт локальный JSON из сохранённого каталога. `--apply` выполняет согласованный импорт после миграции nullable price/available. Перед записью сохраняется резервная копия в игнорируемой папке `work/backups/`. Фото хранятся в постоянном хранилище Image базы, доступном через существующий маршрут `/uploads/UUID.webp`; миниатюра — `/uploads/UUID-thumb.webp`.

Изменения товаров и фото применяются одной транзакцией. Проверяется updatedAt, чтобы не затереть параллельное редактирование. Совпадение ID фотографии проверяется по хешу. Метка `catalog.import.20261108` в Audit не позволяет повторным запуском снова обнулить цены, которые владелец заполнит позже. Существующие product ID и variant ID сохранены; новые варианты получают постоянные уникальные ID и артикулы.

По указанию владельца цена, акционная цена и наличие всех товаров и вариантов устанавливаются в null. Пустое наличие не означает «Нет в наличии». В админке доступны «Не указано», «В наличии», «Нет в наличии». Явное отсутствие товара или варианта имеет приоритет, а true у товара распространяется на варианты без собственного значения.

## WhatsApp

«Заказать» открывает компактную карточку с выбранным фото, названием, указанной ценой и пустым полем сообщения. При поддержке Web Share API кнопка передаёт PNG-карточку с оригинальной фотографией и подписью под ней: название, реальный вариант (если вариантов несколько), указанная цена. Сведения о товаре нарисованы в самой карточке; поле text в Web Share передаётся только при наличии текста, введённого покупателем. Приветствие, предложение уточнить цену, артикулы, внутренние ID и URL в подпись не добавляются.

Получателя через Web Share API выбирает пользователь: WhatsApp и контакт +992906480008. Обычный wa.me не умеет прикреплять файлы или заранее выбирать получателя для системного Share. Кнопка «Открыть чат» использует только собственный текст покупателя; без введённого текста открывает чат с пустым полем. При отсутствии поддержки отправки файлом доступны скачивание фото и открытие чата. Реальная доставка сообщения зависит от приложения WhatsApp и подтверждается пользователем при отправке.
